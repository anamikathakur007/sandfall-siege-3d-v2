SANDFALL SIEGE 3D — UPDATED BUILD

Pages:
- index.php   Home
- play.php    3D desert palace shooter
- scores.php  Leaderboard

Main controls:
- Arrow Up / Down / Left / Right: move
- Mouse: look / aim
- Left mouse: fire
- Right mouse: aim down sights
- Shift: sprint
- R: reload
- Space: jump
- V: switch between Gun View and Full Character

What changed in this build:
- Blue daytime sky
- Faster, more user-friendly movement
- No WASD movement
- Enemies spawn closer and have bright red markers
- Nearest-enemy distance/direction shown in the HUD
- More detailed broken palace with arches, towers, cracked stone and rubble
- More detailed realistic-style assault rifle
- Full-character third-person camera option
- Cleaner tactical HUD

LOCAL XAMPP:
Put this project folder inside C:\xampp\htdocs\sandfall-siege\
Start Apache and open:
http://127.0.0.1/sandfall-siege/

INFINITYFREE:
Upload all project files into your site's htdocs directory.
The game loads Three.js from a public CDN, so visitors need an internet connection.
No MySQL database is required.
